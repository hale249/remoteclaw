# Explain Code

Explain the codebase, a specific file, or a concept.

## Guidelines

- Start with a high-level overview before diving into details
- Use the project's language and domain terminology
- Reference specific files and line numbers
- If explaining architecture, describe the data flow
- Keep explanations concise but thorough
