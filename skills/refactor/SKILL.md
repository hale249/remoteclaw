# Refactor

Refactor the specified code while preserving behavior.

## Guidelines

1. Understand the current behavior first
2. Apply the refactoring the user described
3. Ensure all existing tests still pass
4. Do NOT change public APIs unless explicitly asked
5. Keep changes minimal — only refactor what was requested
6. Explain the key changes made
